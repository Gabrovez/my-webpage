# Моя персональная веб-страница

Простая веб-страница-визитка, созданная в рамках лабораторной работы №6 по курсу Fullstack.

## Содержание страницы
- ФИО и учебная группа  
- Раздел «Обо мне» (3–4 предложения)  
- Список навыков (минимум один)  
- Контактная информация (email и телефон)  
- Изображение (реальное или заглушка)

## Структура проекта
- index.html - Основная HTML-страница 
- style.css - Файл стилей 
- README.md - Вы сейчас его читаете 
- img - Папка с картинкой комару 
- komaru.jpg - Картинка комару
